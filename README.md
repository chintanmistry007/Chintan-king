# Chintan Portfolio Showcase

Modern futuristic portfolio website for Chintan Mistri featuring a dark burgundy aesthetic, glassmorphism card layout, and cinematic entry animations.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Sections included

- Home
- About / Professional Summary
- Education
- Contact
- Skills
- Language
- Achievement
- Certification
